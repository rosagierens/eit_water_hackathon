# E-HYPE sub-basins (v3.0)

ESRI shapefile (zipped) of the 35,408 E-HYPE sub-basins: polygons in WGS84 with `SUBID`, `HAROID` (main catchment), `DOWN` (downstream SUBID), `AREA` and `UPAREA`.

- **Source:** "Level A Pan Europe Subbasins, E-HYPE 3.0", SMHI, Zenodo record 581397, https://zenodo.org/records/581397 (file `SubbasinEHYPEv3pt0.zip`, 22.6 MB)
- **Licence:** CC BY-SA 4.0. Commercial use is allowed; distributed data derived from the map must use the same licence.
- **Accessed:** 2026-10-25
- **Used for:** locating each plant in the sub-basin of the C3S catchment discharge (`e_hypecatch_m00`), whose files only carry sub-basin IDs. All 34,810 IDs of the C3S E-HYPEcatch files (E-HYPE 3.1.6) are in this map (checked 2026-10-25).
- **Caveat:** the map is version 3.0, the discharge comes from 3.1.6. The IDs match, but outlines may differ slightly between versions.
